# urls.txt — posting URLs for batch.py, one per line. Lines starting with # are ignored.
#
#   python batch.py --urls-file urls.txt --dry-run   # fetch + prefilter only, free
#   python batch.py --urls-file urls.txt             # prompts before spending tokens
#
# Supported URL shapes (fetched via each ATS's official public API):
#   Greenhouse       https://job-boards.greenhouse.io/<board>/jobs/<id>
#   Lever            https://jobs.lever.co/<company>/<posting-uuid>
#   Ashby            https://jobs.ashbyhq.com/<org>/<posting-uuid>
#   SmartRecruiters  https://jobs.smartrecruiters.com/<Company>/<id>-<slug>
#   Workable         https://apply.workable.com/<account>/j/<shortcode>/
# Any other careers page works too if it embeds schema.org JobPosting JSON-LD
# (most do); JS-only pages that can't be extracted are reported as fetch failures.
#

# targets; postings expire, and an expired one just shows up as a fetch failure.
